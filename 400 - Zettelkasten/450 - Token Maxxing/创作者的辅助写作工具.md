# 创作者的辅助写作工具

1. 我想为我的个人博客做一个 cms 的后端，可以流畅地写 markdown 并做发布管理。
2. 这样的产品似乎非常 trivial，考虑一些属于我的 niche market。我是一个 ADHD，脑中经常会闪现一些精彩的想法和表达，甚至有可能是并行产生，但是我并不擅长组织想法和写作技巧。因此组织和选用这些想法并最终创造出一篇文章需要占据我大量的时间。
3. 如果借助 AI 可以产生非常符合我想法，精彩且没有 AI 味的文章，这就完美地解决了我的需求。
4. 我的使用方式可能就是记录下杂乱的关于同一个 idea 闪现想法，然后让 ai 帮我组织，让文章自然生长出来。
